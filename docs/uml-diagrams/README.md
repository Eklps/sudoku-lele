# 数独游戏系统 - UML图表集合

## 文件夹说明
本文件夹包含了数独游戏系统的完整UML建模图表，所有图表都使用Mermaid语法创建，可以在支持Mermaid的环境中直接渲染。

## 图表列表

### 1. 用例图 (Use Case Diagram)
- **文件**: `用例图.md`
- **说明**: 展示系统的主要用例和用户交互流程
- **内容**: 创建游戏、填入数字、撤销重做、获取提示等用例

### 2. 类图 (Class Diagram)
- **文件**: `类图.md`
- **说明**: 展示系统的完整类结构和关系
- **内容**: 实体类、控制器、服务层、数据访问层等所有类的详细定义

### 3. 序列图 (Sequence Diagrams)
- **文件1**: `序列图-创建游戏.md`
- **说明**: 展示创建新游戏和填入数字的交互流程
- **内容**: 用户请求、对象创建、移动验证等详细步骤

- **文件2**: `序列图-获取提示.md`
- **说明**: 展示获取智能提示的交互流程
- **内容**: 策略模式应用、提示生成等详细步骤

### 4. 状态图 (State Diagrams)
- **文件1**: `状态图-游戏状态.md`
- **说明**: 展示游戏的整体状态转换
- **内容**: 未开始、进行中、已解决、失败等状态及转换条件

- **文件2**: `状态图-单元格状态.md`
- **说明**: 展示单个单元格的状态转换
- **内容**: 空格、有效数字、无效数字等状态及验证过程

### 5. 架构图 (Architecture Diagram)
- **文件**: `架构图.md`
- **说明**: 展示系统的分层架构设计
- **内容**: 表现层、业务逻辑层、数据访问层、实体层等架构组件

## 使用说明

### 查看图表
1. 在GitHub、GitLab等支持Mermaid的平台上直接查看
2. 使用支持Mermaid的Markdown编辑器（如Typora、VS Code等）
3. 在线Mermaid编辑器：https://mermaid.live/

### 编辑图表
1. 直接编辑对应的.md文件
2. 修改Mermaid代码块中的内容
3. 确保语法正确，可在线验证

### 导出图表
1. 使用Mermaid CLI工具导出为PNG、SVG等格式
2. 在线编辑器中导出图片
3. 使用支持导出的Markdown编辑器

## 建模原则

### 1. 准确性
- 所有图表都基于实际代码创建
- 确保类名、方法名、属性名与代码一致
- 反映真实的系统架构和交互流程

### 2. 完整性
- 涵盖系统的所有主要组件
- 包含关键的业务流程和状态转换
- 展示重要的设计模式应用

### 3. 可读性
- 使用清晰的命名和标注
- 合理的布局和分组
- 详细的说明文档

### 4. 一致性
- 统一的建模风格和符号
- 一致的命名约定
- 相互呼应的图表内容

## 维护说明

### 更新频率
- 代码重构时同步更新图表
- 新增功能时补充相关图表
- 定期检查图表与代码的一致性

### 版本控制
- 图表文件纳入版本控制
- 重要变更记录在提交信息中
- 保持图表与代码版本同步

### 质量保证
- 定期审查图表的准确性
- 确保新团队成员能够理解
- 收集反馈并持续改进
